להתקין את WitBoxInstall WitBox

WitBox בנוי משני חלקים: שרת שמותקן פעם אחת על מחשב לינוקס שנשאר דלוק, ואפליקציות שמתחברות אליו מהטלפון ומהמחשב. הכול עובר רק דרך רשת ה-Tailscale שלכם.

WitBox has two parts: a server installed once on a Linux machine that stays on, and apps that connect to it from your phone and computer. Everything travels only over your Tailscale network.

WitBox נועד להתקנה על גבי רשת Tailscale. לפני שמתחילים: פותחים חשבון Tailscale (חינם), ומפעילים במסוף הניהול, בעמוד DNS, את MagicDNS ואת HTTPS Certificates. בכל מכשיר שממנו תשתמשו ב-WitBox מתקינים Tailscale ומתחברים לאותו חשבון.WitBox is built to be installed on a Tailscale network. Before you start: create a Tailscale account (free) and, in the admin console DNS page, enable MagicDNS and HTTPS Certificates. Install Tailscale on every device you will use WitBox from and sign in to the same account.

1 · השרת1 · The server

שרת לינוקסLinux server

חבילה אחת שמכילה הכול (שרת, ממשק ואפליקציות) וסקריפט התקנה לצידה. הסקריפט מוריד ומתקין את כל התלויות, מחבר ל-Claude ול-Tailscale, ובונה את המחשב של הבוטים. מתאים ל-Debian, Ubuntu, Kali, Mint, Fedora, Arch, Manjaro ו-openSUSE.

One package with everything (server, web UI and apps) and an install script next to it. The script downloads and installs every dependency, signs you in to Claude and Tailscale, and builds the bots' computer. Works on Debian, Ubuntu, Kali, Mint, Fedora, Arch, Manjaro and openSUSE.

שמים את שני הקבצים באותה תיקייה ומריצים:

Put both files in one folder and run:

chmod +x install.sh
./install.sh

או בשורה אחת, והסקריפט מוריד את החבילה בעצמו:

Or in one line — the script downloads the package itself:

curl -fsSL https://github.com/avitwil/WitBox/releases/latest/download/install.sh -o install.sh && bash install.sh
witbox-linux-x86_64.tar.gzinstall.sh

שרת על WindowsServer on Windows ניסיוניExperimental

מתקין אחד ל-Windows. הוא מתקין את האפליקציה, ואם מסמנים "WitBox server on this PC" הוא גם מקים את השרת בתוך WSL2 (Ubuntu). דורש Windows 11 עם וירטואליזציה. המסלול הזה נבדק פחות משרת לינוקס רגיל.

One installer for Windows. It installs the app and, if you tick "WitBox server on this PC", also sets the server up inside WSL2 (Ubuntu). Needs Windows 11 with virtualization. This path has had less testing than a native Linux server.

WitBox-Setup.exe

2 · האפליקציות2 · The apps

בהפעלה הראשונה כל אפליקציה מבקשת את כתובת השרת שהמתקין הדפיס (למשל https://my-server.my-tailnet.ts.net). אחרי ההתקנה השרת מגיש את האפליקציות בעצמו: הגדרות ← עדכונים.

On first start each app asks for the server address the installer printed (for example https://my-server.my-tailnet.ts.net). Once installed, the server also serves the apps itself: Settings → Updates.

AndroidAndroid

טלפון וטאבלט. התראות, שיחת קול ודשבורד. מתירים התקנה מהדפדפן, פותחים ומזינים את כתובת השרת.

Phone and tablet. Notifications, voice chat and the dashboard. Allow installing from your browser, open, and enter the server address.

An installer with shortcuts and start-with-Windows, or a single portable file. The app lives in the system tray.
